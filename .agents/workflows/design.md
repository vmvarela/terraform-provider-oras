# Design

Produce:
- problem;
- desired properties/guarantees;
- non-goals;
- constraints;
- current architecture;
- evidence relied upon;
- proposed design;
- data/state model;
- concurrency model (ownership, generations, actors, races, linearization point if any);
- failure modes including timeout/retry/crash/stale actors;
- compatibility;
- alternatives, including retaining best-effort behavior;
- tests mapped to guarantees;
- risks/unknowns;
- decision.

Prefer the smallest design establishing the required properties.
