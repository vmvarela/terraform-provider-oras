# Investigate

Goal: resolve uncertainty before design/code.

1. State exact question and why it matters.
2. Inspect local source/tests and existing assumptions.
3. Consult current authoritative sources.
4. Inspect upstream implementation/issues/PRs if needed.
5. Design a minimal experiment if semantics remain uncertain.
6. Separate facts, observations, assumptions and unknowns.
7. Recommend next step with HIGH/MEDIUM/LOW confidence.

Do not modify production code merely to answer research unless explicitly requested.
