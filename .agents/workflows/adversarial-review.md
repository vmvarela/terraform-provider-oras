# Adversarial Review

Adopt `.agents/roles/adversary.md`.

1. List claimed guarantees.
2. Identify distributed/shared state.
3. Introduce competing clients.
4. Interleave around read/verify/write boundaries.
5. Add expiry and stale ownership.
6. Add crashes, lost responses and retries.
7. Add registry-specific deviations where relevant.
8. Produce concrete failure scenarios.
9. Map credible scenarios to tests or explicit documented limitations.

An acceptable limitation must still be documented honestly.
