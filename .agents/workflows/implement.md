# Implement

Implement an agreed design with the smallest coherent change.

Before editing, read relevant design/evidence and inspect affected code/tests.

Preserve boundaries, avoid unrelated refactoring, add tests with behavior, handle errors explicitly, and never silently weaken guarantees or invent fallback semantics.

If implementation reveals a false design assumption or broken invariant, stop and report the contradiction rather than silently redesigning.

Before handoff: format, run focused/broader tests as appropriate, inspect diff, report design deviations and residual risks.
