# Architecture Decision Records

Use `NNNN-short-title.md` for durable decisions whose rationale future maintainers/agents need.

Template:

```markdown
# ADR-NNNN: Title
## Status
Proposed | Accepted | Superseded | Rejected
## Context
## Evidence
## Decision
## Alternatives considered
## Consequences
## Risks / limitations
## Verification
## References
```

Good candidates include the locking/consistency model and any future conditional-write decision after evidence exists.
